⚠️ Read this first — model limitations Click to expand ▾
This is a communication and scenario tool, not a forecasting model. Key caveats:

(1) Linear additivity: Factor impacts are summed independently. In extreme regimes (stagflation, financial crisis, Fed pivot), real curve responses are non-linear and the model will overshoot or miss inflection points.
(2) Regime-conditional: Weights are calibrated to the post-2022 hiking cycle. Pre-2008 and zero-lower-bound dynamics differ.
(3) Communication tool: The model is designed to organize macro thinking, not predict future yields. Don't trade off it.
(4) Empirical confidence varies: See source tags in the Weights tab — green = directly cited research, blue = calibrated to literature, orange = estimated.

What this model is — and isn't

It is: A scenario tool to test "what if" questions about the yield curve. Drag a slider, see how the curve would shift. Tell stories about regimes. Communicate macro views clearly.

It is not: A trading model, a forecasting model, or a precision instrument. The math is linear; the world isn't. Use it to organize thinking, not to predict.

The math (simple version)

Implied yield = Actual yield + Σ (weight × Δfactor) × inflation_dampener

For each tenor, the model starts from the actual May 29, 2026 yield. Then for each enabled factor, it multiplies the user's change-from-baseline by an empirically calibrated weight. The sum is the implied yield.

The inflation dampener (new in v5) reduces the combined weight of CPI + Breakeven inflation by 35% to correct for collinearity — they measure overlapping signals and would otherwise be over-counted.

14 factors (down from 24)

Earlier versions had 24 factors. Empirical analysis found significant collinearity — CPI/PCE/Breakeven/Trade inflation were 80%+ correlated; GDP/Unemployment/Recession overlapped on growth signal; Oil/Hormuz/GPRI all measured the same shock. v5 consolidates to 14 orthogonal factors:

Empirical sources

Each Empirical weight is anchored to specific research:

  • CBO 2024 (Gamber-Seliski): Debt-to-GDP coefficient ≈ 2bp per 1% of GDP
  • Dallas Fed WP 2513: 80%+ of debt effect flows through term premium, not expected rates
  • Fed Board FEDS Note Feb 2026: Term premium and forward rates explain 80%+ of 10yr variation
  • NY Fed SR 810 (Hanson-Stein-Sunderam): 10yr-1yr coefficient 0.56 historical, 0.85 post-2000
  • Adrian-Crump-Moench (2013): Term premium decomposition methodology
  • NBER WP 30476: Foreign reserve flows — $100B shock moves 10yr by 100bp+
  • San Francisco Fed Dec 2025: Oil supply news sensitivity
  • FRED CPI vs 10yr regression: R² ≈ 0.4 over 1955-2024

Sanity checks

Current baseline: Model output matches actual yield curve exactly. ✓ (by construction)

Recession scenario: 2yr drops sharply (Fed cuts), 10yr drops less, curve steepens. Output matches 2008/2020/2024 cutting cycles. ✓

Stagflation scenario: Long end rises while Fed funds rises slowly. Output: 30yr +120-180bp. Consistent with 1970s regimes. ✓ (Note: real stagflation regimes also feature flat curves from Volcker-style hikes — model under-captures this)

Soft landing: Inflation falls, Fed cuts, long end falls. 10yr -50 to -80bp from baseline. ✓

Known limitations (be honest with yourself)

1. Linear additivity. Real yield dynamics are non-linear. Stagflation + recession can't both be true; the model adds them anyway.

2. Conflict warnings only. Regime warnings alert you when the scenario is internally inconsistent, but the model still runs the math.

3. Calibrated to current regime. Coefficients reflect 2022-2026 dynamics. Pre-2008 or ZLB-era would differ.

4. No uncertainty bands. Point estimates only. Real 10yr forecasts should have ±30-50bp confidence intervals.

5. No regime detection. The same weight applies whether we're in a normal market or a financial crisis.

Quick start (60 seconds)

1. Click a scenario button (Current, Stagflation, Soft landing, Recession) to load a preset.

2. Drag any slider to test "what ifs". Blue line updates live, dashed green stays at actual yields.

3. Hit 💾 Save to keep an interesting view.

4. Use Compare tab to overlay scenarios side-by-side.

5. Use 📄 PDF to export a research-note-style report.

Tuning the model to your view

If you think a factor doesn't matter: Uncheck its toggle in the Model tab to remove it from the math entirely.

If you think a factor matters more/less: Go to Weights tab, scale its multiplier up/down (0% to 300%).

If you disagree with how factors co-move: Go to Linkages tab and edit the coefficients directly.

All customizations persist in your browser. Reset buttons are scoped to each panel.
